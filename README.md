# Palindrom-Number
A palindrome number is a number that remains the same when its digits are reversed. In other words, it reads the same from left to right as it does from right to left.

# 5-Digit Palindrome Checker in Python

A simple and beginner-friendly Python script designed to check whether a given 5-digit number is a **palindrome** (a number that reads the same forwards and backwards, e.g., `12321`).

## Features
- Takes an integer input from the user.
- Extracts individual digits (ten-thousands, thousands, hundreds, tens, and units) using mathematical operations (`//` and `%`).
- Validates if the number is a palindrome.
- Outputs whether the number is a palindrome and displays its separated digits.
